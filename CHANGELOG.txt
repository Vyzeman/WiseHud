WiseHud Changelog
=================

Version 1.1.4
-------------
- Added WoW Forever support (Interface 16001) via WiseHud_Forever.toc.
- Guarded secret health, power, and cast values so the HUD keeps updating on Forever.

Version 1.1.3
-------------
- Updated Interface version to 120005.

Version 1.1.2
-------------
- Added absorb handling to the health bar to better visualize shields.
- Updated orb handling to support WoW 12.0 secret predicates.

Version 1.1.1
-------------
- Tweaked rune handling for Death Knights for more accurate updates.

Version 1.1.0-beta
------------------
- Added Death Knight support for resource orbs.
- Added configuration for orb size to better match personal preference and UI scale.

Version 1.0.4
-------------
- Added orb alpha settings and improved visibility handling.
- Improved cast bar logic to avoid stale events affecting the display.
- Refined options panel layout, padding, and section anchoring for better consistency.

Version 1.0.3
-------------
- Refined orb names and presets for better customization.
- Extended layout options for orbs and the options panel.
- Improved alpha and layout handling for the health and power modules.

Version 1.0.2
-------------
- Various internal cleanups and minor improvements.

Version 1.0.1
-------------
- Initial public release including:
  - Health and resource bars.
  - Combo point orbs for multiple classes.
  - Configurable options via the interface options menu.
